# Communication Preferences

- Communicates primarily in Thai; expects responses in Thai. Confidence: 0.9
- Writes short, informal messages with casual particles (e.g., "หน่อยสิ") and occasional typos (e.g., "brach"); comfortable with a relaxed, concise tone. Confidence: 0.7
- Prefers evidence-backed technical discussion: provides exact file:line citations, code snippets, and concrete diagnostics rather than vague feature requests. Expects the assistant to meet the same standard of accuracy. Confidence: 0.9
- Corrects inaccuracies firmly and explicitly — will reject fabricated or ungrounded content (e.g., fake code references) by supplying the real analysis. Confidence: 0.8
- Drives long work sessions with terse one-word continuation/status prompts (e.g., "ต่อ" = continue, "ทำหมดยัง" = done yet?) rather than restating context, expecting the assistant to resume the in-flight task from memory and re-verify status. Confidence: 0.8
- Expects structured, evidence-backed completion reports in Thai (e.g., numbered verification results, pass/fail tables) summarizing what was done and verified, rather than bare confirmations. Confidence: 0.6

Confidence: 0.6
